# campaigns.tasks

## list

List campaign tasks

```bash
revenexx campaigns-tasks list
```

## create

Add a task to a campaign

```bash
revenexx campaigns-tasks create \
    --campaign-id '' \
    --title ''
```

## delete

Delete a task

```bash
revenexx campaigns-tasks delete \
    --id ''
```

## get

Read one task

```bash
revenexx campaigns-tasks get \
    --id ''
```

## update

Correct a task

```bash
revenexx campaigns-tasks update \
    --id ''
```

## complete

Tick a task off

```bash
revenexx campaigns-tasks complete \
    --id ''
```

## reopen

Open a task again

```bash
revenexx campaigns-tasks reopen \
    --id ''
```
