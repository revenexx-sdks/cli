# quotes.acceptance

## accept

Accept a quote, whole or line by line

```bash
revenexx quotes-acceptance accept \
    --id ''
```

## decline

Decline a quote

```bash
revenexx quotes-acceptance decline \
    --id ''
```

## ordered

Record the order a quote produced

```bash
revenexx quotes-acceptance ordered \
    --id '' \
    --order-id ''
```

## reject

Refuse to quote

```bash
revenexx quotes-acceptance reject \
    --id '' \
    --reason ''
```
