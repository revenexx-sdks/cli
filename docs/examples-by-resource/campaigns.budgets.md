# campaigns.budgets

## list

List budget lines

```bash
revenexx campaigns-budgets list
```

## create

Add a budget line

```bash
revenexx campaigns-budgets create \
    --campaign-id '' \
    --line ''
```

## delete

Delete a budget line

```bash
revenexx campaigns-budgets delete \
    --id ''
```

## get

Read one budget line

```bash
revenexx campaigns-budgets get \
    --id ''
```

## update

Correct a budget line

```bash
revenexx campaigns-budgets update \
    --id ''
```
