# audiences.rules

## list

List audience rules

```bash
revenexx audiences-rules list
```

## create

Add a rule or a group to an audience

```bash
revenexx audiences-rules create \
    --audience-id ''
```

## delete

Remove a rule (and, for a group, what it holds)

```bash
revenexx audiences-rules delete \
    --id ''
```

## get

Read one rule

```bash
revenexx audiences-rules get \
    --id ''
```

## update

Correct a rule

```bash
revenexx audiences-rules update \
    --id ''
```
