# ads.links

## list

List ad campaigns and their campaigns

```bash
revenexx ads-links list
```

## create

List an ad campaign

```bash
revenexx ads-links create \
    --ad-account-id '' \
    --external-campaign-id ''
```

## delete

Remove an ad campaign without spend

```bash
revenexx ads-links delete \
    --id ''
```

## get

Read one ad campaign link

```bash
revenexx ads-links get \
    --id ''
```

## update

Map an ad campaign to a campaign

```bash
revenexx ads-links update \
    --id ''
```
