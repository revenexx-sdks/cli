# avatars

## get-browser

Get browser icon

```bash
revenexx avatars get-browser \
    --code aa
```

## get-credit-card

Get credit card icon

```bash
revenexx avatars get-credit-card \
    --code amex
```

## get-flag

Get country flag

```bash
revenexx avatars get-flag \
    --code af
```

## get-image

Get image from URL

```bash
revenexx avatars get-image \
    --url https://www.revenexx.com/img/hero-revenexx-poster.webp
```

## get-initials

Get user initials

```bash
revenexx avatars get-initials
```

## get-qr

Get QR code

```bash
revenexx avatars get-qr \
    --text ''
```

## get-screenshot

Get webpage screenshot

```bash
revenexx avatars get-screenshot \
    --url https://example.com
```
