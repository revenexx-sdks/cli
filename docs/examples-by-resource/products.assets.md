# products.assets

## list

List assets

```bash
revenexx products-assets list
```

## create

Create asset

```bash
revenexx products-assets create \
    --asset-family-id '' \
    --code acme-4711-blk_packshot_1
```

## empty-trash

Empty the trash of assets

```bash
revenexx products-assets empty-trash
```

## delete

Move asset to the trash, or delete it for good

```bash
revenexx products-assets delete \
    --id ''
```

## get

Get asset

```bash
revenexx products-assets get \
    --id ''
```

## update

Update asset

```bash
revenexx products-assets update \
    --id ''
```

## restore

Restore asset from the trash

```bash
revenexx products-assets restore \
    --id ''
```
