# reviews.aggregates

## list

Read the review figures of many products

```bash
revenexx reviews-aggregates list
```

## rebuild

Recompute review figures from the published reviews

```bash
revenexx reviews-aggregates rebuild
```

## review-stars

Read how the review's product is rated, as bar rows

```bash
revenexx reviews-aggregates review-stars \
    --id ''
```
