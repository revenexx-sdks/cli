# promotions.evaluation

## available

List the promotions this buyer could still reach

```bash
revenexx promotions-evaluation available \
    --currency ''
```

## check-code

Say whether one code is live, without a cart

```bash
revenexx promotions-evaluation check-code \
    --code ''
```

## evaluate

Answer what a priced cart is owed, writing nothing

```bash
revenexx promotions-evaluation evaluate \
    --currency ''
```

## vocabularies

List the closed vocabularies this app enforces

```bash
revenexx promotions-evaluation vocabularies
```

## vocabulary

Read one vocabulary

```bash
revenexx promotions-evaluation vocabulary \
    --name ''
```
