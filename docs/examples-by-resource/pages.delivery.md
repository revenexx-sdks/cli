# pages.delivery

## menus

List navigation menus for the renderer

```bash
revenexx pages-delivery menus
```

## page

Resolve a published page by slug or id

```bash
revenexx pages-delivery page
```

## pages

List published pages

```bash
revenexx pages-delivery pages
```

## popups

List the pop-ups a visitor may see

```bash
revenexx pages-delivery popups
```

## preview

Resolve a preview token to a page

```bash
revenexx pages-delivery preview \
    --preview-token ''
```

## site-settings

Read the site settings for rendering

```bash
revenexx pages-delivery site-settings
```

## template

Resolve the template page of a record

```bash
revenexx pages-delivery template
```
