# ads.conversions

## list

List recorded conversions

```bash
revenexx ads-conversions list
```

## get

Read one conversion

```bash
revenexx ads-conversions get \
    --id ''
```

## result

Report whether a conversion was sent

```bash
revenexx ads-conversions result \
    --id ''
```

## retry

Put a failed conversion back in line

```bash
revenexx ads-conversions retry \
    --id '' \
    --body '{ "key": "value" }'
```
