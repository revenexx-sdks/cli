# mailings.analysis

## list-clicks

List clicked links of mailings

```bash
revenexx mailings-analysis list-clicks
```

## get-click

Read one clicked link

```bash
revenexx mailings-analysis get-click \
    --id ''
```

## list-engagements

List recorded reactions to mailings

```bash
revenexx mailings-analysis list-engagements
```

## get-engagement

Read one recorded reaction

```bash
revenexx mailings-analysis get-engagement \
    --id ''
```

## clicks

Read the click map of a mailing

```bash
revenexx mailings-analysis clicks \
    --id ''
```

## stats

Read what a mailing achieved

```bash
revenexx mailings-analysis stats \
    --id ''
```

## timeline

Read the opens and clicks of a mailing per day

```bash
revenexx mailings-analysis timeline \
    --id ''
```

## list-stats

List the figures of mailings

```bash
revenexx mailings-analysis list-stats
```

## sweep

Bring the figures of the last 30 days up to date

```bash
revenexx mailings-analysis sweep \
    --body '{ "key": "value" }'
```

## get-stats

Read one figures row

```bash
revenexx mailings-analysis get-stats \
    --id ''
```
