# products.references

## reference-entities-list

List reference entities

```bash
revenexx products-references reference-entities-list
```

## reference-entities-create

Create reference entity

```bash
revenexx products-references reference-entities-create \
    --code brand
```

## reference-entities-delete

Delete reference entity

```bash
revenexx products-references reference-entities-delete \
    --id ''
```

## reference-entities-get
