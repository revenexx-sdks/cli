# locale

## get

Get user locale

```bash
revenexx locale get
```

## list-codes

List locale codes

```bash
revenexx locale list-codes
```

## list-continents

List continents

```bash
revenexx locale list-continents
```

## list-countries

List countries

```bash
revenexx locale list-countries
```

## list-countries-eu

List EU countries

```bash
revenexx locale list-countries-eu
```

## list-countries-phones

List countries phone codes

```bash
revenexx locale list-countries-phones
```

## list-currencies

List currencies

```bash
revenexx locale list-currencies
```

## list-languages

List languages

```bash
revenexx locale list-languages
```
