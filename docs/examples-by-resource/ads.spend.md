# ads.spend

## figures

Read the spend, clicks and conversions of an ad account per day

```bash
revenexx ads-spend figures \
    --id ''
```

## roas

Read the return on ad spend of a campaign

```bash
revenexx ads-spend roas \
    --campaign-id ''
```

## list

List imported daily ad spend

```bash
revenexx ads-spend list
```

## import

Import daily ad spend per ad campaign

```bash
revenexx ads-spend import \
    --rows one two three
```

## get

Read one day of ad spend

```bash
revenexx ads-spend get \
    --id ''
```
