# consent-manager.policy

## banner-get

Read the banner draft for this market (or the shop's)

```bash
revenexx consent-manager-policy banner-get
```

## banner-update

Save the banner draft for this market

```bash
revenexx consent-manager-policy banner-update
```

## versions-list

List the published versions

```bash
revenexx consent-manager-policy versions-list
```

## versions-get

Read one published version

```bash
revenexx consent-manager-policy versions-get \
    --id ''
```

## preview

Render the draft and answer a preview token

```bash
revenexx consent-manager-policy preview
```

## publish

Freeze the draft as the next policy version

```bash
revenexx consent-manager-policy publish
```
