# quotes.ranges

## list

List number ranges

```bash
revenexx quotes-ranges list
```

## create

Create a number range

```bash
revenexx quotes-ranges create \
    --code ''
```

## defaults

Seed the standard number range

```bash
revenexx quotes-ranges defaults
```

## delete

Remove a number range

```bash
revenexx quotes-ranges delete \
    --id ''
```

## get

Read one number range

```bash
revenexx quotes-ranges get \
    --id ''
```

## update

Change a number range

```bash
revenexx quotes-ranges update \
    --id ''
```
