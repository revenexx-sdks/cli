# tag-manager.tags

## registry-list

List the supported registry keys

```bash
revenexx tag-manager-tags registry-list
```

## list

List marketing tags

```bash
revenexx tag-manager-tags list
```

## create

Create a marketing tag

```bash
revenexx tag-manager-tags create
```

## delete

Delete a marketing tag

```bash
revenexx tag-manager-tags delete \
    --id ''
```

## get

Read one marketing tag

```bash
revenexx tag-manager-tags get \
    --id ''
```

## update

Edit a marketing tag

```bash
revenexx tag-manager-tags update \
    --id ''
```

## triggers-list

List a marketing tag's triggers

```bash
revenexx tag-manager-tags triggers-list \
    --id ''
```

## triggers-attach

Attach a trigger to a marketing tag

```bash
revenexx tag-manager-tags triggers-attach \
    --id '' \
    --trigger-id ''
```

## triggers-detach

Detach a trigger from a marketing tag

```bash
revenexx tag-manager-tags triggers-detach \
    --id '' \
    --trigger-id ''
```
