# campaigns.assets

## list

List the assets campaigns hold

```bash
revenexx campaigns-assets list
```

## get

Read one asset row

```bash
revenexx campaigns-assets get \
    --id ''
```

## detach

Release the asset an asset row names

```bash
revenexx campaigns-assets detach \
    --id '' \
    --body '{ "key": "value" }'
```
