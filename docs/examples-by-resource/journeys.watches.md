# journeys.watches

## list

List notification requests

```bash
revenexx journeys-watches list
```

## create

Ask to be told when a product is back

```bash
revenexx journeys-watches create
```

## delete

Withdraw a notification request

```bash
revenexx journeys-watches delete \
    --id ''
```

## get

Read one notification request

```bash
revenexx journeys-watches get \
    --id ''
```
