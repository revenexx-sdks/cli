# journeys.enrollments

## list

List enrollments

```bash
revenexx journeys-enrollments list
```

## get

Read one enrollment

```bash
revenexx journeys-enrollments get \
    --id ''
```

## exit

Take a person out of a journey

```bash
revenexx journeys-enrollments exit \
    --id '' \
    --body '{ "key": "value" }'
```
