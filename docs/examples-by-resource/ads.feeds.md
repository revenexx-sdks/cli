# ads.feeds

## list

List the product feeds handed to ad platforms

```bash
revenexx ads-feeds list
```

## create

Name the seo feed of a market for a destination

```bash
revenexx ads-feeds create \
    --destination google_merchant_center \
    --market ''
```

## delete

Remove a feed reference

```bash
revenexx ads-feeds delete \
    --id ''
```

## get

Read one feed reference

```bash
revenexx ads-feeds get \
    --id ''
```

## update

Change a feed reference

```bash
revenexx ads-feeds update \
    --id ''
```
