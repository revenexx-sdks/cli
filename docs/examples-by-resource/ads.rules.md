# ads.rules

## list

List conversion rules

```bash
revenexx ads-rules list
```

## create

Add a conversion rule

```bash
revenexx ads-rules create \
    --ad-account-id '' \
    --event order.placed \
    --name ''
```

## delete

Delete a rule that recorded nothing

```bash
revenexx ads-rules delete \
    --id ''
```

## get

Read one conversion rule

```bash
revenexx ads-rules get \
    --id ''
```

## update

Correct a conversion rule

```bash
revenexx ads-rules update \
    --id ''
```
