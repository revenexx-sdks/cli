# sales-reps.acting-for

## impersonations-list

List every occasion a rep acted for a buyer

```bash
revenexx sales-reps-acting-for impersonations-list
```

## impersonations-create

Record that a rep acted for a buyer

```bash
revenexx sales-reps-acting-for impersonations-create \
    --contact-id '' \
    --organization-id '' \
    --rep-code VK-04711
```

## impersonations-delete

Erase one entry from the log

```bash
revenexx sales-reps-acting-for impersonations-delete \
    --id ''
```

## impersonations-get

Read one occasion a rep acted for a buyer

```bash
revenexx sales-reps-acting-for impersonations-get \
    --id ''
```
